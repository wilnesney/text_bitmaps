# Text Bitmaps

A collection of simple, text-based, 4-tone "bitmaps" (not in BMP format) to 
experiment with.

Each bitmap consists of characters in the range 0-3, representing light/tone 
values going from dark to light. Suggested characters to draw for these could be
(space), -, +, and #. Line breaks separate each row of pixel values.

Bitmap dimensions are powers of 2 (e.g., 64x32) to simplify scaling.
